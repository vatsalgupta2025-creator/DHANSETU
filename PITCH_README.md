## 🛠️ Tech Stack

- **Frontend**: Next.js 16 + React 19 + TypeScript
- **Styling**: Tailwind CSS 4 + Framer Motion
- **AI/ML**: XGBoost-style risk scoring, Recharts analytics
- **Voice**: ElevenLabs Multilingual TTS API
- **Data**: 500+ synthetic loan records with realistic risk profiles

---

## 🎯 Key Features

### AI Negotiation Bot
- Conversational interface in **23 Indian languages**
- Understands hardship situations (job loss, medical emergency, business loss)
- Offers personalized repayment plans
- Escalates to human agents when needed

### Risk Engine
- Real-time risk scoring (0-100)
- Predicts 30/60/90-day default probability
- Recommends best channel (WhatsApp/SMS/Call/Email)
- Identifies uplift potential (persuadability score)

### Command Center
- Live portfolio tracking
- AI-powered recommendations
- Agent leaderboards
- ROI analytics

### Compliance Center
- RBI guideline adherence
- Audit trails
- Automated compliance checks
- Real-time alerts

### Voice Cloning
- Natural-sounding speech in Hindi, Tamil, Telugu, and more
- Browser-based fallback if API unavailable
- Gender-specific voices available
